# 🛠️ web-utility-projects

A collection of web projects aimed at enhancing productivity and providing useful web utilities. This repository includes:

- ✅ To-Do List App
- 🐶 Dog Image Search App (using Fetch API)
- 💱 Device Converter Tool

---

## 📖 Introduction

**web-utility-projects** is a set of simple yet effective web applications built using HTML, CSS, and JavaScript. These projects are ideal for learning, practicing, or quick deployment for personal use. Each tool serves a unique purpose, from managing your daily tasks to searching for adorable dog images and converting currencies.

---

## ✨ Features

- **To-Do List App**  
  Organize your tasks with a user-friendly interface. Add, remove, and track your daily goals efficiently.

- **Dog Image Search App**  
  Search and display random dog images by breed using the Fetch API and the [Dog CEO API](https://dog.ceo/dog-api/).

- **Device (Currency) Converter Tool**  
  Convert between different currencies instantly with a clean design and real-time updates.

---

## 🛠️ Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/web-utility-projects.git
   ```
2. **Navigate to the project folder:**
   ```bash
   cd web-utility-projects/Web utility projects
   ```
3. **Open any `.html` file in your web browser:**
   - `Convertisseur de devises.html`
   - `Liste de tâches (To-Do List).html`
   - `Recherche d'images de chiens.html`

> **No additional setup required!**  
> All projects are fully client-side and require only a web browser.

---

## 🚀 Usage

- **To-Do List App:**  
  Open `Liste de tâches (To-Do List).html` and start adding your tasks. Mark them as completed or delete as needed.

- **Dog Image Search App:**  
  Open `Recherche d'images de chiens.html`. Enter a dog breed and view images instantly fetched from the API.

- **Device Converter Tool:**  
  Open `Convertisseur de devises.html`. Select currencies, enter the amount, and view the conversion results.
